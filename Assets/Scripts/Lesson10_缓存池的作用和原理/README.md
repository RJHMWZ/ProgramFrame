# 一、缓存池（对象池）的主要作用
**重复利用已经创建过的对象，避免频繁创建和销毁对象，从而减少内存分配和垃圾回收带来的开销。**
减少 Instantiate，减少 Destroy，重复使用已有对象
从而降低：内存分配、GC压力、频繁创建销毁带来的性能消耗

# 二、缓存池（对象池）的基本原理
## 1. 获取对象
当需要一个对象时：向对应的池中查找——池中有对象——直接取出复用
如果池中没有：池中没有对象——创建一个新对象
## 2. 回收对象
对象暂时不用时，不直接销毁：
对象使用结束——放回对应对象池——等待下次继续使用

# 三、对象池的整体流程
```
	  需要对象
		 ↓
	 查询对象池
		 ↓
	是否存在可用对象？
		 ↓
 ┌───────┴───────┐
 ↓               ↓
有               没有
 ↓               ↓
取出复用        创建新对象
 ↓               ↓
 └───────┬───────┘
         ↓
       使用对象
         ↓
       使用结束
         ↓
       放回对象池
```
