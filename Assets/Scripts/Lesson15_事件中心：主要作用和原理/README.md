# 一、事件中心解决的问题
例如怪物死亡后，需要通知多个系统：
```text
怪物死亡
├── 玩家获取奖励
├── 任务系统更新任务信息
├── 成就系统更新
└── 副本系统更新
```
如果怪物直接引用这些系统，对象和模块之间会互相依赖。随着系统增多，引用关系会越来越复杂，耦合度也会越来越高，不利于开发和维护。

# 二、事件中心的主要作用
事件中心用于：
- 解耦程序模块。
- 降低程序耦合度。
- 让不同系统、模块和对象不必直接引用彼此的具体实现。

# 三、事件中心的基本原理
事件中心是一个集中处理事件的中间模块。
```text
事件发送者
    ↓
事件中心
    ↓
所有关注该事件的系统
```
例如怪物死亡时，怪物只需要通知事件中心。玩家奖励、任务、成就和副本等系统通过事件中心接收通知，不需要由怪物逐个调用。
事件中心主要结合以下内容实现：
- 使用 `Dictionary` 管理不同事件。
- 使用委托记录事件触发后需要执行的方法。
- 使用观察者设计模式建立一对多的通知关系。
==观察者设计模式：当一个对象的状态发生变化时，所有依赖它的对象都会收到通知并进行更新。==
